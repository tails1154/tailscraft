# TailsCraft third-party notices

## Baritone pathing adaptation

TailsCraft includes a compatibility port of the basic command/pathing surface
from Baritone's 1.12.2-era release `v1.2.19` (`d9cb2d91a06501c5bcba2181509d0df80361f413`).
The TailsCraft implementation adapts that release's command conventions and
movement-search behavior to the 1.12.2/WASM API; Forge-only mixins and runtime
components are not bundled.
